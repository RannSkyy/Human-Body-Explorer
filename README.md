# 🧬 Human Body Explorer

An interactive educational web application designed to help middle school students learn human anatomy through engaging visual exploration, interactive lessons, and fun quizzes.

## ✨ Features

- 🧠 Interactive human body exploration
- 🫀 External body and internal organ visualization
- 📖 Easy-to-understand learning materials
- 🔍 Organ search and navigation
- 🎯 Interactive quizzes with instant feedback
- 🎮 Gamified learning experience
- 🔊 Sound effects and voice pronunciation
- 🎉 Animated quiz results and achievements
- 📱 Fully responsive (Mobile, Tablet, Laptop, Desktop)
- 💾 Local progress saving

## 🎓 Target Users

- Middle School Students (Grades 7–9)
- Science Teachers
- Parents

## 📚 Topics Covered

- Human Body Parts
- Skeletal System
- Muscular System
- Respiratory System
- Circulatory System
- Digestive System
- Excretory System
- Nervous System
- Healthy Lifestyle

## 🚀 Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Web Audio API
- Web Speech API
- LocalStorage

## 🎯 Objectives

- Make anatomy learning more interactive and enjoyable.
- Improve students' understanding of human body systems.
- Encourage self-paced learning through exploration and quizzes.
- Support teachers with an engaging digital learning medium.
